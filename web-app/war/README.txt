CCalculatorGWT - Suite Mathématique Complète
============================================

Version: 1.0.0
Date: [Date de publication]
Auteur: CalculatorGWT Team

DESCRIPTION
-----------
CalculatorGWT est une application web sophistiquée développée en Java GWT 
offrant une suite complète d'outils mathématiques pour les étudiants, 
enseignants et professionnels.

FONCTIONNALITÉS PRINCIPALES
---------------------------
1. Calculatrice scientifique standard
2. Solveur d'équations complexes (ComplexEquationSolver)
3. Calculs matriciels avancés (MatrixCalculator)
4. Calculs polynomiaux (PolynomeCalculator)
5. Statistiques à deux variables (StatDeuxVariables)
6. Calculs de PGCD et PPCM (PGCDPPCMCalculator)
7. Génération d'histogrammes (HistogrammeJuxtapose)
8. Fonctions mathématiques élémentaires (StaticElem42GWT)
9. Système d'aide intégré (Aide)

PRÉREQUIS SYSTÈME
-----------------
- Java Runtime Environment (JRE) 8 ou supérieur
- Navigateur web moderne (Chrome, Firefox, Safari, Edge)
- 512 MB RAM minimum (1 GB recommandé)
- 50 MB d'espace disque libre

INSTALLATION RAPIDE
-------------------
1. Décompressez le fichier CalculatorGWT.zip
2. Ouvrez le dossier 'war'
3. Lancez le fichier CalculatorGWT.html dans votre navigateur
4. L'application se charge automatiquement

UTILISATION
-----------
1. Lancez CalculatorGWT.html dans votre navigateur
2. Sélectionnez le module désiré dans le menu principal
3. Suivez les instructions spécifiques à chaque module
4. Consultez l'aide intégrée (bouton 'Aide') pour plus d'informations

MODULES DÉTAILLÉS
-----------------
- MatrixCalculator : Opérations sur matrices, déterminants, inverses
- PolynomeCalculator : Résolution et analyse de polynômes
- ComplexEquationSolver : Équations complexes et nombres complexes
- StatDeuxVariables : Analyses statistiques et régressions
- PGCDPPCMCalculator : Calculs arithmétiques fondamentaux

DÉPANNAGE
---------
Problème courant : L'application ne se charge pas
Solution : Vérifiez que JavaScript est activé dans votre navigateur

Problème courant : Erreurs de calcul
Solution : Vérifiez le format des données d'entrée

Pour plus d'aide : consulter docs/MANUAL.pdf ou contact.html
